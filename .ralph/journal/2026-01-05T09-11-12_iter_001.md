# Iteration 1: Implementing Journal Search Capability

## The Bigger Picture
The ralph-journal plugin currently stores journal entries but lacks discovery mechanisms. This work aims to add a `/search-journals` command that enables keyword-based search across all journal files, making past insights and learnings accessible. The end goal is a fully functional search feature with tests and documentation that integrates seamlessly into the existing plugin architecture.

## Iteration Goals
- [ ] Implement basic `/search-journals` command with keyword argument
- [ ] Add file system traversal for `.ralph/journal/*.md` files
- [ ] Return matching entries with surrounding context
- [ ] Write comprehensive tests for search functionality
- [ ] Document the new command in plugin docs
- [ ] Validate through testing and fix any issues discovered

## The Plan
1. Start with core search implementation: argument parsing and file reading
2. Build keyword matching logic with context extraction (surrounding lines)
3. Format and return results in user-friendly manner
4. Create test suite covering edge cases (no matches, multiple matches, special characters)
5. Add documentation explaining usage and examples
6. Run tests and iterate on any failures
